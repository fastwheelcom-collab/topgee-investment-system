📋 How to Save & Use This Backup

  1. Click Download Backup Now — file saves to your Mac mini's Downloads folder
  2. Move it to a safe folder like ~/Desktop/TopGee Backups/
  3. Name it clearly — the file already includes date + time in the name
  4. To restore: send the file to Tom and say "restore this backup" — Tom knows the format
  5. Recommended: take a backup every week or before making big changes

🔄 How to Restore from Backup

If data is lost or you move to a new server, share the JSON backup file with Tom.
Tom will read the file and restore all investors, transactions, and revenue history exactly as they were.
The format is structured so Tom can verify each record before restoring.
